# 安装、升级与卸载

## 下载哪一个

去 [v0.7.8 发布页](https://github.com/SSNQ/reeden-kobo/releases/tag/v0.7.8)，下载 `Reeden-Kobo-Adapter-v0.7.8-OneClick.zip`，完整解压后操作。不要只下载单个 `.command` 或 `.bat`。附件中的 `COMMIT.txt` 对应源提交，`SHA256SUMS` 可用于校验下载文件。

仅支持 **Kobo Clara Colour（产品代码 393）**，已测固件 **4.46.23836**。需先装 NickelMenu；电脑需 Python 3.10+。本安装器不安装 NickelMenu，也不覆盖固件。USB 安装不需要 SSH、KOReader、Zig 或 C 编译器。

## 新安装

安装器会先检查已连接的 USB 设备，再下载和组包：机型不匹配、缺少 NickelMenu、仍有 Reeden 会话锁或命令行升级未加 `--upgrade` 时会提前停止。双击安装器仍保留原有的自动识别旧版、保留数据升级流程；实际写入前会再次检查设备和空间。SSH 或仅本地组包不会扫描 USB。

1. 备份重要书籍和笔记，退出其他阅读器，回到 Kobo 原生主界面。
2. USB 连接电脑，在 Kobo 屏幕点「连接」，电脑出现 KOBOeReader 盘。
3. 在解压目录双击「一键安装-macOS.command」或「一键安装-Windows.bat」；Linux 运行 `sh 一键安装-Linux.sh`。
4. 按提示选择官方包。支持官方 Kindle 1.43.2+791 / 1.43.1+780，校验不匹配的包会拒绝安装；官网下载的“最新版本”如果更新到白名单之外，也需要等待适配验证。
5. 完成后安全弹出 USB，在 NickelMenu 点「Reeden Kobo - Check」，确认通过后点「Reeden Kobo (test)」。

安装需要从固定来源下载运行库和字体，请保持电脑联网；已校验下载会缓存。macOS 如果拦截脚本，按 README 的右键打开或终端方式操作。Windows 需先安装 Python 3.10+；脚本优先使用 `py -3`，否则使用 `python`。

多个设备同时连接时不会自动选择第一台。请仅保留一台，或运行：

```sh
python3 install.py --kobo-mount /Volumes/KOBOeReader
```

Windows 将示例路径换成实际盘符，如 `E:\`。终端路径含空格时加引号。

## 只检查，不安装

想先确认 USB 连接和安装前提是否满足，可以在解压目录打开终端运行：

```sh
python install.py --check
```

macOS/Linux 使用 `python3`。连接多台 Kobo 时，可明确选择其中一台，例如 Windows：

```powershell
python install.py --check --kobo-mount E:\
```

此模式不联网、不下载官方包、不组包、不创建或修改设备文件。它检查产品代码、NickelMenu 目录和活动会话锁，显示固件版本，但不输出序列号；已有安装无需加 `--upgrade`。检测失败会返回非零退出状态。

检查通过不代表任意固件兼容、屏幕残影已解决或剩余空间足够。本项目已测固件仍为 **4.46.23836**；实际安装会根据安装包和需保留的数据计算空间，并重新检查设备。`--check` 不能与 SSH、`--output` 或官方包相关选项混用。

## 官方包选择与校验

Mac 上请解压本项目的 OneClick ZIP，但不要解压官方核心 `Reeden-kindle.zip`。Finder 给解压目录添加的隐藏文件会改变已校验文件集合；遇到提示时选择原始 Kindle ZIP，不要删除文件或关闭完整性校验。

自动发现会按顺序验证本地候选，跳过损坏、资源不配套或不支持的包，选择首个有效包；本地已有受支持的 780 时可以继续使用。显式 `--official-core /path/to/Reeden-kindle.zip` 只使用指定包，失败即停止。

`--download-official` 强制从官网联网下载，不使用发现的旧包；与 `--official-core` 互斥。下载写入独立 `.part`，校验通过后才替换 `cache/Reeden-kindle.zip`。网络中断或 ZIP 截断最多尝试三次，失败清理半包并保留原缓存，不静默回退。无有效本地候选时，交互直接回车也会执行此下载流程。

791 使用随项目提交的纯文本清单核对官方核心目录全部 243 个文件及精确文件集合，覆盖资源、字体、随包运行库和许可证。780 保留两份核心库的原 SHA-256 白名单，并核对资源版本、必要文件和字体引用；未取得其官方原包，尚不能进行完整文件哈希校验，安装器会明确提示这一限制。

2026-11-04 只读检查确认官网 latest 仍为 1.43.2+791。官网 Kindle 文档及官方 GitHub Releases 未提供可验证的 Kindle 历史包链接，历史版本探测及版本 JSON 端点返回 404，因此没有写入推测的版本下载地址。若 latest 更新到白名单外，下载会拒绝并保留旧缓存；可用 `--official-core` 显式指定已保存的受支持官方包，或等待后续适配。

## 保留数据升级

交互安装时看到「保留书库与进度升级」再按回车；输入其他内容（包括「取消」）不会写入设备。自己改过的 Reeden 菜单会保留原样，新版默认菜单在 `.adds/reeden-kobo/nickelmenu.conf`，无需重新添加自己的菜单项。只有当原菜单与上次发布的标准菜单完全一致时才会被替换。如果原菜单读不出来（权限或 I/O 错误），安装器会保留它并在输出里提示，**不会因此回滚已经完成并校验通过的安装**——这种安装完成后请手动对照新版默认菜单。

普通用户只需：

1. 下载新版完整 ZIP，解压到一个新文件夹。
2. 在 Kobo 上退出 Reeden，连接 USB，在屏幕点“连接”。
3. 双击 **一键更新-Windows.bat**（macOS 双击 **一键更新-macOS.command**；Linux 运行 `sh 一键更新-Linux.sh`）。
   也可以先打开更新工具，再接 USB 数据线并在阅读器上点“连接”。交互窗口最多等待约一分钟；超时后重新打开即可，等待期间不会下载或写入。
4. 等待“USB 一键升级完成”，安全弹出 Kobo，再启动 Reeden。

不需要输入命令参数或手动选择安装方式。工具自动识别已有安装，保留书库、笔记、进度、冷暖光设置和原有诊断配置，并保留完整旧版备份。它先查找本地官方包，找不到时自动从官网获取，仍需通过白名单校验。官网下载中断或核心校验失败不会将本次下载保存为正式缓存；网络恢复后可以重新运行。

**此入口更新的是“本次下载包里的适配层版本”，不是自动从 GitHub 获取新版工具。** 每次更新仍需先下载新版 ZIP；不要重复运行旧文件夹中的更新入口并期待它变成新版。电脑仍需 Python 3.10+；没有旧安装时会提示改用“一键安装”，不会误做全新安装。

机型不符、会话未退出、多台设备、空间不足或官方核心超出支持范围时会停止。下载和组包后会再次核对目标设备，防止中途换接另一台 Kobo。官方核心更新到白名单之外时，需要使用已支持的官方包或等待适配，不会跳过校验硬装。

原来的“一键安装”仍可自动识别并升级旧版。开发者也可使用以下等价入口：

```sh
python3 install.py --update
```

需要自行管理官方包或其他高级选项时，原命令仍保留：

```sh
python3 install.py --usb --upgrade
```

安装器在准备并校验新版、复制阅读数据后，再替换当前目录；旧版保留于 `.adds/reeden-kobo-backup-日期-随机码/`。升级期间需要容纳额外副本，空间不足时拒绝开始写入。异常会尝试恢复；断电、拔线和磁盘损坏不能保证自动恢复。成功确认新版本正常后，可自行备份并清理旧目录。

## 一键卸载

先退出 Reeden。若启用过 Reeden SSH，先重启设备再连接 USB，关闭仍在内存中的 SSH 监听和已有会话；USB 卸载器不能操作设备进程。

双击「一键卸载-macOS.command」或「一键卸载-Windows.bat」；Linux 运行 `sh 一键卸载-Linux.sh`。卸载不下载任何东西，不需要官方包，但同目录的 `install.py` 必须保留。电脑仍需 Python 3.10+。

- **1：保留完整备份（默认）**。将当前 `.adds/reeden-kobo/` 改名为 `.adds/reeden-kobo-uninstalled-日期-随机码/`。移除未改动的标准菜单；保留整个应用、书籍、笔记、进度、设置和可能存在的诊断密钥。备份仍占设备空间，可复制到电脑确认后手动删除。
- **2：删除当前安装及阅读数据**。输入 `DELETE REEDEN` 后删除当前安装目录，其中的书籍、笔记、进度和诊断密钥一并删除。以前的升级/卸载备份不会自动删除，因此不等于清空设备上的所有 Reeden 历史数据。

自定义菜单不会被整文件删除，工具会提示相关文件名，需手动移除其中 Reeden 项。不移除 NickelMenu 本体、KOReader、原生书籍或固件。工具遇到会话锁、错误机型、多个 USB 设备或固定路径上的符号链接时停止。菜单删除失败会尝试恢复原安装；彻底删除中途失败会报告剩余目录供人工处理。

命令行：

```sh
python3 uninstall.py --usb
python3 uninstall.py --kobo-mount /Volumes/KOBOeReader
python3 uninstall.py --usb --purge
```

自动化场景可明确加 `--yes` 跳过确认，`--purge --yes` 会直接删除当前安装及阅读数据，不建议普通用户使用。

## 设备端卸载脚本

在设备上运行 `sh /mnt/onboard/.adds/reeden-kobo/uninstall.sh` 会先将整份安装移动到同分区的独立备份目录，成功后再删除未被修改的标准菜单。移动失败时程序和入口保持原状；若菜单删除失败，脚本返回失败并报告已保存的备份路径，按提示手工处理菜单。设备端脚本保留数据，不提供彻底删除操作。

## 卸载后恢复备份

仅对“保留完整备份”或升级备份适用：

1. 回到原生界面，USB 连接电脑。
2. 确认 `.adds/reeden-kobo/` 不存在；如已重新安装，先备份当前目录，不要覆盖、合并两份阅读数据库。
3. 将选定的完整备份目录改名为 `.adds/reeden-kobo/`。
4. 将其内部 `nickelmenu.conf` 复制为 `.adds/nm/reeden-kobo`；如目标菜单已自定义，先备份并人工检查，避免覆盖其他菜单项。
5. 安全弹出，先自检再启动。备份版本仍需满足当前机型和固件要求；旧版本的已知问题不会因恢复而消失。

备份包含私人数据和可能的 SSH 主机/认证配置，请勿上传 GitHub 或公开分享。
