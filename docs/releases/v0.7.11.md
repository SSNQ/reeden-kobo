# Reeden Kobo v0.7.11 (Experimental)

专注**流畅度、续航与纯白底抗残影**的专项优化版本：引入异步刷屏流水线、固化 REAGL 抗残影扫动默认策略、降低静态与菜单空转功耗，并补全磁吸休眠皮套与长时间无操作自动深睡支持。

## 更新亮点

- **连翻更跟手、冷启动更快**：引入独立异步显示工作线程（墨水屏刷屏期间不再阻塞触控与下一页渲染），优化单趟像素/色彩扫描与显存写入，取消刷新完成后的多余冷却等待；优化原生退出等待与完整性归档校验，缩短冷启动耗时。
- **纯白底残影修复（默认开启 REAGL 抗残影扫动）**：在已测 Clara Colour（`1072×1448`, `rotate=3`）上将 REAGL 分段（`GLR16 + FULL`）固化为内置默认（保留 `REEDEN_TEXT_BAND_PATH=stable` 回退），纯白底水波纹翻页显著减少文字残影。
- **续航与日常体验升级**：
  - Flutter 刷新率默认调为 `20Hz`，大幅减少菜单与书架滑屏时的软件渲染空转耗电；
  - 后台守护进程唤醒间隔放宽至 `15s` 并零 fork 解析进程状态（实机连续运行 86 分钟 `guardian.sh` 累计 CPU `0:00`）；
  - 新增 **磁吸休眠皮套（Hall 传感器 `/dev/input/event0`）** 合盖自动休眠 / 开盖唤醒；
  - 新增 **15 分钟无操作自动深睡** 与未开自定义封面时的快速熄灯；
  - 整合新版一键安装器终端实用提示。

## 老用户升级方法

1. 先在 Kobo 上退出 Reeden（**同时按住屏幕左上角 + 右上角约 2 秒**回到原生主界面）。
2. 用 USB 数据线连接电脑，在 Kobo 屏幕点击「连接」。
3. 下载本页附件 `Reeden-Kobo-Adapter-v0.7.11-OneClick.zip`，**完整解压**后双击 `一键安装-macOS.command` 或 `一键安装-Windows.bat`（Linux 运行 `sh 一键安装-Linux.sh`），按回车即可自动识别旧版并保留数据升级（原书库、阅读进度、笔记和冷暖光设置全部保留）。
4. 安全弹出 USB，点击右下角 `NickelMenu → Reeden` 启动。确认新版运行正常后，可手动删除 Kobo 上的 `.adds/reeden-kobo-backup-*` 旧版备份目录释放空间。

## 推荐阅读设置（获得最佳观感）

- **纯白底主题**：建议在 Reeden 阅读设置中开启「水波纹翻页（快档）」，普通「翻页动画」选「无动画」，翻页更利落且抗残影更干净。
- **彩色壁纸 / 边框主题**：`v0.7.10` 引入的 `smooth` 策略已默认保留；建议在 Reeden 设置中开启 **定期全刷（每 6～10 页一次）**，既可保持画卷静止不闪，又能定期清零轻微残影；满屏深色/画卷背景上若觉文字略淡，可将字体调深（纯黑）并略调前光。
- **锁屏与日常操作**：推荐在「我的 → 墨水屏」开启「自定义锁屏画面」；支持电源键短按或磁吸皮套合盖休眠/唤醒；**同时按住屏幕左上角 + 右上角约 2 秒**退出回 Kobo 原生系统。

- **实机验证（Kobo Clara Colour 393 / 固件 4.46.23836 / 1.43.2+791）**：设备端 `verify.sh` 全部通过（全文件 SHA-256、`fb-guard --inspect`、动态库检查与全部 7 项 ARMHF 合成测试）；实机确认 `[color-refresh] profile=smooth text_bands=reagl`、`[engine] display refresh_rate=20Hz`、`[display] async worker started`、`[power] sleep cover hall sensor acquired (/dev/input/event0)` 与 `[power] idle_sleep_sec=900`；连续阅读约 86 分钟 `guardian.sh` 累计 CPU `0:00`，白底 `path=reagl` 与《番茄》画卷翻页运行稳定。
