# Reeden Kobo v0.7.9 (Experimental)

针对用户反馈的「Clara Colour 在 macOS 一键安装完成后，Kobo 原生图书管理（我的图书）被塞进近两百个图标成为未读图书」，为 USB 与 SSH/设备端安装流程自动补齐 Kobo 原生系统的隐藏目录忽略配置（`ExcludeSyncFolders`）。

## 根因说明

- Kobo 4.17 及以上固件的原生系统（Nickel）不会默认跳过 `.adds/` 隐藏目录，而是会把其中图片（`.png`/`.jpg`）与文本（`.txt`/`.html`）当作未读图书入库。
- Reeden 安装包在 `.adds/reeden-kobo/` 下包含 `core/data/flutter_assets` 与 `ui-assets` 两份界面资源、文档截图和许可文本（全新安装合计 166 个原生系统可扫描文件，其中 137 张图片、29 个文本/网页）。
- 此前测试设备因已装过 KOReader，`.kobo/Kobo/Kobo eReader.conf` 早已存在 `ExcludeSyncFolders`；仅安装了 NickelMenu、未安装过 KOReader 的新设备缺少该配置，导致退出 USB 后图标全部被扫入书架。

## 本版改动

- **USB 安装器（`install.py`）与设备端安装脚本（`scripts/install.sh`）自动配置忽略规则**：
  - 在完成安装提交后，自动检查 `.kobo/Kobo/Kobo eReader.conf` 的 `[FeatureSettings]` 段并补齐 `ExcludeSyncFolders=(\.(?!kobo|adobe).+|([^.][^/]*/)+\..+)`。
  - 若设备已有涵盖 `.adds` 的规则（例如 KOReader 写入的配置），保持原文件原字节不动，不重复写节头。
  - 若设备已有其他自定义规则（如排除 `manga` 等目录），在校验正则合法后自动合并保留原规则；若遇到带引号或无法解析的自定义规则，则保持原配置不动并打印人工处理提示。
  - 保留 Qt `@ByteArray(...)` 原始字节、统一写入 Unix LF 换行、原子替换并清理 macOS AppleDouble (`._Kobo eReader.conf`)，安装前先校验配置路径不含符号链接。
- **安装完成后给出明确提示**：区分全新配置、已有配置和升级场景，提示首次写入忽略规则后安全弹出并重启一次 Kobo 让原系统加载配置。

## 已有图标用户的处理步骤

如果之前用旧版安装后原系统书架已经扫进了大量图标：

1. 下载并完整解压 `Reeden-Kobo-Adapter-v0.7.9-OneClick.zip`，连接 USB 后运行一键安装（自动保留书库与进度升级，并补齐 `ExcludeSyncFolders`）。
2. 安全弹出 USB 后**重启一次 Kobo**，让原生系统加载忽略规则并清理旧书库条目（如未自动清理，可再连线并安全弹出一次）。
3. 注意：Kobo 原生系统在清理此前已入库的条目时，可能会顺带删除磁盘上已被索引的旧图标/文本文件；如重启后自检提示文件缺失，再次连接电脑运行一次 v0.7.9 一键安装（保留数据升级）即可恢复完整文件，且此后不会再被扫入书架。

## 验证与范围

- 本版仅修改电脑安装器、设备端安装脚本、文档与回归测试，未改动 C 适配层源码或预编译二进制；发行 CI 继续校验预编译件逐字节一致、Linux C 回归、QEMU 及三平台 Python 3.10/3.12 回归。
- 新增 `tests/kobo_exclude_sync_test.py` 并在 `tests/oneclick_installer_test.py`、`tests/install_upgrade_test.py` 补充回归，覆盖空白/缺失配置、无重复 `[FeatureSettings]`、已有 KOReader 规则原样保留、自定义规则合并、无效/引号规则保护、CRLF 规范化、Qt `@ByteArray` 原始字节保留、AppleDouble 清理与符号链接拦截。
- 本轮未在全新未装 KOReader 的实体机上重测原系统首次冷扫描与清理全过程；Kobo 不同固件对 `Kobo eReader.conf` 热重载时机存在差异，因此仍明确建议首次写入忽略规则后重启一次设备。

支持范围仍为 Kobo Clara Colour（产品代码 393），已测固件 4.46.23836，电脑需 Python 3.10+，设备需 NickelMenu。官方 Kindle 核心白名单仍为 1.43.2+791 / 1.43.1+780。
