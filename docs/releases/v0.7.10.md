# Reeden Kobo v0.7.10 (Experimental)

针对用户反馈的「彩色壁纸与边框主题翻页出现整块内框闪动、旧字粗边闪烁与色彩发灰」以及「默认 NickelMenu 菜单项过多」问题，正式上线 `smooth` 彩色刷新策略并精简默认启动菜单。

## 本版改动

1. **彩色背景与边框主题翻页刷新优化（默认 `smooth` 策略）**：
   - 在已测 Clara Colour（`1072×1448`, `rotate=3`）上统一使用原生 `EINK_NORMAL`（`flags=0`），原样输出 RGB 像素，保持清屏、翻页与菜单之间的色彩增益一致，不压缩淡彩画卷亮度与饱和度。
   - 彩色翻页采用全屏 `GL16`（夜间 `GLKW16`）+ `UPDATE_MODE_PARTIAL`（`mode=0`）：未变化的画卷背景像素保持 `0V` 不动（实测 ~81.5% 静态像素零电压），单次翻页耗时从 ~720–920ms 降至 ~430ms，消除白底边框主题下 `GLRC16` 的 `30→29` Regal 粗边闪烁与正文内框整块闪动。
   - 非翻页菜单/弹窗保持 48 像素对齐的 `GLRC16 + FULL`，显式清屏与彩色休眠封面保持 `GCC16 + FULL`，兼顾无菜单残影。夜间稀疏彩字分页（`refresh_night_parts`）与纯白灰阶翻页扫动保持不变。
   - 保留 `REEDEN_COLOR_REFRESH=legacy` 回退开关（非法值安全回退为默认 `smooth`）。
   - 说明：受 Kaleido 3 面板波形 ROM 物理特性限制，在彩色/中灰底（`0 → 18/24/28`）上擦除黑墨仍需经过短暂回拉校准，单次彩色翻页会有约 80ms 的轻微旧字回闪，属于硬件波形下限。
2. **精简默认 NickelMenu 菜单**：
   - `.adds/nm/reeden-kobo`（`scripts/nickelmenu.conf`）精简为与 KOReader 一致的单一启动项 `Reeden`，移除普通用户不需要的 `Check`、`Return Home` 与 `SSH - Stop` 菜单项（`precheck.sh`、`recover.sh`、`reeden-ssh.sh` 仍保留在安装包目录供排障使用；`run.sh` 启动时会自动完成完整性校验与残留会话恢复）。
   - 同步更新 USB/SSH 安装器提示、文档与 NickelMenu 审计回归测试。

## 验证与范围

- **本地 C 与 Python 回归**：`sh scripts/test-turn-offline.sh`（ASan/UBSan）、`codec_test`、`light_panel_test` 以及全部 `tests/*.py`（含安装/升级、安全审计、资源恢复、核心校验、`ExcludeSyncFolders` 等）全部通过。
- **可复现预编译验证**：Zig 0.13.0 重建 `scripts/build.sh` 与 `scripts/build-headless.sh`，全部产物与 `prebuilt/` 及 `prebuilt/PREBUILT_SHA256SUMS` 逐字节一致。
- **实机验证（Kobo Clara Colour 393 / 固件 4.46.23836 / 1.43.2+791）**：设备端 `verify.sh` 全部通过（全文件 SHA-256、`fb-guard --inspect`、动态库检查与全部 7 项 ARMHF 合成测试）；实机在多款边框主题与满屏画卷壁纸、菜单开关及更新后的单一 `Reeden` NickelMenu 入口下验证通过。

支持范围仍为 Kobo Clara Colour（产品代码 393），已测固件 4.46.23836，电脑需 Python 3.10+，设备需 NickelMenu。官方 Kindle 核心白名单仍为 1.43.2+791 / 1.43.1+780。
