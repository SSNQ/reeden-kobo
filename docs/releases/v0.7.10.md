# Reeden Kobo v0.7.10 (Experimental)

针对用户反馈的「彩色壁纸与边框主题翻页出现整块内框闪动、旧字粗边闪烁与色彩发灰」以及「默认 NickelMenu 菜单项过多」问题，正式上线 `smooth` 彩色刷新策略并精简默认启动菜单。

## 更新亮点

- **彩色壁纸与画卷主题翻页更稳、更快、更通透**：彩色翻页速度提升约 40%（降至约 0.4 秒），背景画卷静止不闪动，白底边框主题不再出现内框整块闪动或粗边重影，淡彩画卷保持原本通透色彩。
- **NickelMenu 菜单精简为唯一入口 `Reeden`**：与 KOReader 风格统一，移除普通用户用不上的自检、恢复和 SSH 停止菜单项（`run.sh` 启动时会自动完成完整性校验与异常恢复，排障脚本仍保留在设备目录中）。
- **老用户无痛保留数据升级**：升级自动保留现有书库、阅读进度、笔记和冷暖光设置，同时自动将旧版多条 NickelMenu 菜单精简为 `Reeden`。

## 老用户升级方法

1. 先在 Kobo 上退出 Reeden（**同时按住屏幕左上角 + 右上角约 2 秒**回到原生主界面）。
2. 用 USB 数据线连接电脑，在 Kobo 屏幕点击「连接」。
3. 下载本页附件 `Reeden-Kobo-Adapter-v0.7.10-OneClick.zip`，**完整解压**后双击 `一键安装-macOS.command` 或 `一键安装-Windows.bat`（Linux 运行 `sh 一键安装-Linux.sh`），按回车即可自动识别旧版并保留数据升级。
4. 安全弹出 USB，点击右下角 `NickelMenu → Reeden` 启动。确认新版运行正常后，可手动删除 Kobo 上的 `.adds/reeden-kobo-backup-*` 旧版备份目录释放空间。

## 推荐阅读设置（获得最佳观感）

- **纯白底主题**：建议在 Reeden 阅读设置中开启「水波纹翻页（快档）」，普通「翻页动画」选「无动画」，翻页更利落。
- **彩色壁纸 / 边框主题**：`v0.7.10` 开箱即已优化；在满屏画卷或深色花纹背景上如果觉得文字略淡，可将字体调深（纯黑）并略调前光，同时保持 Reeden 自带的定期全刷开启。
- **锁屏与日常操作**：推荐在「我的 → 墨水屏」开启「自定义锁屏画面」；短按电源键休眠/唤醒；**同时按住屏幕左上角 + 右上角约 2 秒**退出回 Kobo 原生系统。

1. **彩色背景与边框主题翻页刷新优化（默认 `smooth` 策略）**：
   - 在已测 Clara Colour（`1072×1448`, `rotate=3`）上统一使用原生 `EINK_NORMAL`（`flags=0`），原样输出 RGB 像素，保持清屏、翻页与菜单之间的色彩增益一致，不压缩淡彩画卷亮度与饱和度。
   - 彩色翻页采用全屏 `GL16`（夜间 `GLKW16`）+ `UPDATE_MODE_PARTIAL`（`mode=0`）：未变化的画卷背景像素保持 `0V` 不动（实测 ~81.5% 静态像素零电压），单次翻页耗时从 ~720–920ms 降至 ~430ms，消除白底边框主题下 `GLRC16` 的 `30→29` Regal 粗边闪烁与正文内框整块闪动。
   - 非翻页菜单/弹窗保持 48 像素对齐的 `GLRC16 + FULL`，显式清屏与彩色休眠封面保持 `GCC16 + FULL`，兼顾无菜单残影。夜间稀疏彩字分页（`refresh_night_parts`）与纯白灰阶翻页扫动保持不变。
   - 保留 `REEDEN_COLOR_REFRESH=legacy` 回退开关（非法值安全回退为默认 `smooth`）。
   - 说明：受 Kaleido 3 面板波形 ROM 物理特性限制，在彩色/中灰底（`0 → 18/24/28`）上擦除黑墨仍需经过短暂回拉校准，单次彩色翻页会有约 80ms 的轻微旧字回闪，属于硬件波形下限。
2. **精简默认 NickelMenu 菜单**：
   - `.adds/nm/reeden-kobo`（`scripts/nickelmenu.conf`）精简为与 KOReader 一致的单一启动项 `Reeden`，移除 `Check`、`Return Home` 与 `SSH - Stop` 菜单项（`precheck.sh`、`recover.sh`、`reeden-ssh.sh` 仍保留在 `.adds/reeden-kobo/` 目录供排障使用）。
